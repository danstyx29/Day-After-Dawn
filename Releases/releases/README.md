# Archived builds

Every playable build of the game from before it moved to GitHub, kept for the record. Each file is the complete game as it was at that version: open it in a browser to play it. Dates are when the version was made (from the changelog), not the upload date. The game was called **Dead Quiet** until v1.8, when it became **Day After Dawn**. The full notes for every version are in [docs/CHANGELOG.md](../docs/CHANGELOG.md).

> **About this project:** Day After Dawn is an independent, non-commercial fan project inspired by *Project Zomboid*. All of its code, art, names and text are original. It is not affiliated with or endorsed by The Indie Stone. Some early builds may still contain place names that were renamed in the 1.13.1 clean-up.

**Kept:** 24 builds. **Not kept:** 1.4. The changes in 1.4 are described in the changelog, and every later build includes them.

**About the rebuilt builds:** 1.9, 1.9.1, 1.9.2, 1.9.3, 1.9.4 and 1.10 were rebuilt on 16 Oct 2026. Each started from the nearest real build (1.9.5 for the 1.9 series, 1.10.1 for 1.10), and the later patches were undone one at a time, using the exact changes recorded when each patch was made. Every rebuilt build was checked: it passes a syntax check, identifies as exactly its version from its contents, and starts a game without errors. They work the same as the originals, but they aren't guaranteed to be byte-for-byte identical copies.

**How complete this is:** for 1.0 to 1.4, the saved conversation logs list every build that was handed over (times in UTC). All of them are here except 1.4: three rounds of 1.0, then one build each for 1.1, 1.2, 1.3 and 1.4. For 1.5 onwards, each version was released once, as listed in the changelog, and every one is here, original or rebuilt. The one build that was never released is the round 3 work in progress, and it's labelled as such.
